잇다 설치 방법
==============

1. 이 폴더의 파일을 모두 같은 폴더에 둡니다.
   (zip 파일로 받았다면 먼저 "압축 풀기"를 해 주세요. zip 안에서 바로 실행하면 설치되지 않습니다.)

2. ITDA-Setup-(버전).exe 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   - 관리자 권한은 필요 없습니다.

3. 설치가 끝나면 "지금 잇다 실행하기"를 체크한 채 [마침]을 누릅니다.
   - 처음 실행할 때는 AI 모델을 등록하느라 몇 분 걸립니다. 진행 창이 닫힐 때까지 기다려 주세요.
   - 준비가 끝나면 브라우저에 잇다 화면이 열립니다.

다음부터는 바탕화면이나 시작 메뉴의 "잇다" 아이콘을 누르면 됩니다.
잇다를 끄려면 화면 오른쪽 아래 알림 영역의 잇다 아이콘을 오른쪽 클릭 → [종료].

필요한 것: Windows 10/11 64비트, 빈 디스크 공간 약 15GB (설치를 마친 뒤에는 약 9GB 사용)
